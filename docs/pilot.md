# 8문항 파일럿 계획

기획안 1단계. 원문 접근 방식과 해설 형식을 확정하고, 문항당 작성·검수 시간을 잰다.

## 문항 선정 (2027학년도 수능 수학 공통, 최신 회차 우선)

2026-11-27 공식 문제지(홀수형)를 보고 확정. 8문항 모두 초안 작성 완료(`status: draft`). 정답 대조 완료, 나머지 검수 남음.

| 유형 | 번호 | 형식 | 내용 | 정답 (홀수형) |
| - | - | - | - | - |
| 짧은 계산 | 2 | 5지선다 2점 | 미분계수의 정의 | ⑤ 10 |
| 짧은 계산 | 9 | 5지선다 4점 | 속도와 움직인 거리 (방향 전환) | ④ 12 |
| 그래프 해석 | 4 | 5지선다 3점 | 그래프로 좌·우극한 읽기 | ④ 4 |
| 그래프 해석 | 14 | 5지선다 4점 | 로그함수 평행이동 + 무게중심 | ④ 7/2 |
| 그래프 해석 | 19 | 단답 3점 | 삼차함수와 가로선의 교점 개수 | 31 |
| 고난도 | 15 | 5지선다 4점 | 우극한으로 정의된 함수의 불연속 | ③ 8 |
| 고난도 | 21 | 단답 4점 | 구간 최댓값·최솟값의 곱, 미분가능성 | 135 |
| 고난도 | 22 | 단답 4점 | 주기 수열 + 로그 + Σ | 98 |

초안 답은 손풀이와 수치 계산(파이썬)으로 교차 확인한 뒤, 2026-11-27 평가원 정답표(`27DaeSuneung_2a.pdf`, 11-19 공개 가채점본)와 대조해 8문항 모두 값·선택지 번호가 일치했다(`answer-check` 기록). 짝수형은 9번만 선택지 번호가 다르다(②). **12월 1일 확정 정답 발표 후 한 번 더 확인한다.**
고난도(15, 21, 22)는 `difficulty: hard` → 해설을 보지 않은 사람의 독립 재풀이가 필요하다.
초안 작성 시간은 사람이 쓴 것이 아니므로 `minutes`에 기록하지 않았다. 파일럿 시간 측정은 검수 시간과, 사람이 새로 쓰는 문항으로 잰다.

## 학생 관찰 (5명, 휴대전화)

과제: "2027 수능 ○번 풀이를 찾아서, 힌트만 보고 첫 발상을 자기 말로 설명해 주세요."

기록할 것:
- 검색에서 문항 페이지 도착까지 걸린 시간과 막힌 지점
- 힌트만 보고 첫 발상을 설명했는지 (예/부분/아니오)
- **원문 확인 방식 비교**: 공식 PDF를 새 탭으로 열어 해당 문항을 찾는 데 걸린 시간과 불편 정도. 문항 조건을 자체 문장으로 요약해 보여주는 시안과 비교한다(요약 방식은 저작권 검토 후에만 실제 반영).
- **차별점 비교**: 같은 문항을 기존 무료 해설(SN, mathlab 등) 하나와 나란히 보여주고, 어느 쪽이 첫 식을 더 빨리 이해하게 했는지 묻는다.

## 통과 기준

- 학생 5명 중 4명 이상이 지정 문항을 2분 안에 찾는다.
- 힌트만으로 첫 발상을 설명한 비율이 과반.
- 문항당 작성+검수 시간 중앙값으로 66문항 소요를 다시 계산한다 (가정: 20~40분/문항 → 22~44시간).
- 원문 접근 방식(링크 / 요약)을 확정하고 `docs/content-guide.md`에 반영한다.
