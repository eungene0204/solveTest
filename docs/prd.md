# 제품 요구사항 (PRD)

기획 초안(2026-11-27)을 요구사항 단위로 정리한 문서. 소프트웨어 요구사항 명세(SRS)의 역할을 겸한다: 요구사항마다 ID, 통과 기준, 현재 상태를 둔다.
변경 시 이 문서를 먼저 고치고 코드에 반영한다. 용어는 `GLOSSARY.md`를 따른다.

## 1. 목적

시험을 준비하는 사람이 막힌 기출문항을 검색하면, 회원가입 없이 힌트와 검수된 풀이를 바로 볼 수 있게 한다.

**차별점**: 모든 해설에서 **첫 식을 세우는 근거(첫 발상)**와 **자주 틀리는 지점**을 같은 위치에 보여준다.
비교 대상: EBSi(해설지·강의), mathlab.kr(연도·시험별 풀이), SN독학기숙학원(2027 수능 수학 웹 해설).

**수익**: 공개 문항 페이지의 광고.

## 2. 사용자와 상황

| 사용자 | 상황 | 원하는 것 |
| - | - | - |
| 재도전하려는 수험생 | 기출을 풀다 특정 문항에서 막힘 | 정답을 보지 않고 출발점만 (힌트) |
| 채점을 마친 수험생 | 틀린 문항의 풀이를 확인 | 원하는 단계부터 읽기, 왜 그 식인지 |
| 운영자 | 해설 작성·검수 | 초안 → 검수 → 공개 → 수정·공개 중지 |

주 사용 환경은 휴대전화. 대부분 외부 검색(“2027 수능 22번”)으로 문항 페이지에 바로 도착한다.

## 3. 범위

**첫 출시 (In)**: 2025·2026·2027학년도 수능 수학 공통 각 22문항(총 66). 최신 회차부터 제작.

**후속 검토 (Out)**: 수학 선택과목, 평가원 6·9월 모의평가, 수능 타 과목, 국가시험, 해외 시험(SAT는 College Board 이용 조건상 별도 기획), 학생 계정, 자동 채점, 사진 문제 인식, AI 채팅.

## 5. 비기능 요구사항

| ID | 요구사항 | 통과 기준 |
| - | - | - |
| NFR-01 | 모바일 우선 | 375px 폭에서 가로 스크롤 없음, 수식·그림이 읽힘 |
| NFR-02 | 로그인 없음 | 모든 학생 화면을 계정 없이 이용 |
| NFR-03 | 학생 식별정보 미수집 | 신고·측정·광고 어디에서도 연락처나 식별자를 요구하지 않음. 측정은 세션 내 열람 문항 id만 |
| NFR-04 | 정확성 | 공개 문항은 공식 정답 대조 + 다른 사람의 풀이 검수. 고난도는 독립 재풀이 |

| NFR-06 | 원문 출처 표시 | 문제 본문마다 시행기관·학년도·시험·시험지 유형 표기 |
| NFR-07 | 다크 모드 | 본문·수식·그림 모두 다크 모드에서 읽힘 |
| NFR-08 | 운영비 | 정적 호스팅만으로 운영 가능 (서버·DB 없음) |

## 6. 발행 흐름

**초안 → 정답 대조 → 풀이 검수 → 모바일 미리보기 → 공개.** 고난도 또는 풀이가 애매한 문항은 독립 재풀이를 추가한다. 세부 규칙은 `docs/content-guide.md`.

## 7. 성공 지표

- **핵심 지표: 두 번째 문항 열람률.** 풀이 페이지를 본 세션 중 다른 문항을 하나 더 본 세션의 비율.
- 첫 4주 판단 기준(가설): 풀이 방문 300세션 이상에서 15% 이상.
- 보조 지표: 검색 유입 문항 수, 힌트 사용률, 확인된 중대 오류, 문항당 작성·검수 시간, (광고 적용 시) 실제 RPM.
- 표본이 작거나 수능 직후 유입에 쏠리면 판단 전에 측정 기간을 늘린다.

## 8. 가정과 제약

- 문항당 작성·검수 20~40분 → 66문항 약 22~44시간 (파일럿에서 재산정).
- 광고 수익 가정: 페이지 RPM 2,000원 → 월 10만 PV에 약 20만 원 (비용 차감 전).
- 2028학년도 수능부터 수학 선택과목 체제가 바뀌므로 개념 태그에 2015·2022 개정 과목명을 함께 기록한다.
- 원문은 저작권이 시행기관에 있다. 문제 본문을 옮겨 적어 보여주는 결정과 그 위험은 ADR 0003.
