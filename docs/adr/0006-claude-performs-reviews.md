# 검수는 Claude가 하고, 학생 관찰은 하지 않는다

사용자 결정(2026-11-27)에 따라 정답 대조뿐 아니라 풀이 검수(`solution-review`), 독립 재풀이(`independent-resolve`), 모바일 미리보기(`mobile-preview`)도 Claude가 한다. 검수에 참여할 사람과 관찰할 학생이 없기 때문이다. 1단계 파일럿의 학생 5명 관찰과 그 통과 기준은 취소했다.

이전 원칙("작성자가 아닌 사람이 검수", NFR-04)은 작성자의 맹점을 다른 눈으로 잡기 위한 것이었다. 작성자와 검수자가 같은 모델이면 이 효과가 약해지므로, 검수를 작성과 **분리된 절차**로 둔다.

- **풀이 검수**: 작성 맥락과 별개로, 원문 대조 이미지(`.cache/crops/`)와 해설을 한 줄씩 대조한다. 숫자·부호·첨자·배점, 조건 적용, 경우 누락, 수식 변형을 `docs/review-sheet.md` 항목대로 확인한다. 가능한 계산은 코드로 다시 한다.
- **독립 재풀이**: 해설을 보지 않은 새 맥락에서 문제 본문만으로 다시 풀어 답을 맞춘다. 같은 풀이를 되읽는 것은 재풀이로 치지 않는다.
- **모바일 미리보기**: 실제 기기 대신 헤드리스 Chrome 375px 폭에서 가로 넘침을 자동 검사하고, 화면을 캡처해 그림·상자·수식을 눈으로 확인한다.

## Consequences

- `reviews`의 `by`에는 `Claude`를 적고, `note`에 방법(예: "375px 헤드리스 검사")을 남긴다. 사람이 나중에 검수하면 새 기록을 추가한다.
- 공개 조건(`publishBlockers`)은 그대로다. 검수 단계를 줄이지 않고 수행 주체만 바뀌었다.
- 같은 모델의 공통 맹점은 남는다. 공개 후 오류 신고와 즉시 공개 중지 절차(`docs/content-guide.md`)가 마지막 안전장치다. 사람 검수자가 생기면 고난도 문항부터 사람 검수를 더한다.
- 사용자 반응 근거(찾기 시간, 힌트만으로 첫 발상 설명)는 공개 후 측정 지표(두 번째 문항 열람률 등)로 대신한다.
