# 문제 본문은 캡처하지 않고 텍스트로 다시 입력한다

문항 페이지에 문제를 바로 보여주되, 공식 PDF 캡처 대신 텍스트·KaTeX 수식·다시 그린 SVG 그림으로 옮겨 적는다(`problem` 필드, `src/figures/`). 캡처는 휴대전화에서 흐리고 확대·검색·다크 모드가 안 되며, 학생이 PDF를 따로 열어 문항을 찾는 흐름은 너무 번거롭다는 사용자 판단에 따랐다. 평가원에 이용 허락은 문의하지 않기로 했다.

## Considered Options

- 공식 문제지 링크만 제공(기획 초안의 최초안): 저작권 위험이 가장 낮지만 문제를 보기 어렵다는 피드백으로 폐기.
- PDF 캡처 이미지, 배포 빌드는 허락 전까지 제외: 화질 문제로 폐기. `npm run crop`은 원문 대조용으로만 남겼다.

## Consequences

- 원문의 저작권은 평가원에 있고, 광고가 붙는 사이트에 원문을 옮겨 싣는 위험을 감수한다. 출처 표기와 하단 저작권 문구를 유지하고, 요청 시 즉시 내릴 수 있게 한다.
- 옮겨 적기 오타가 새 오류 원인이 되므로 원문 대조를 검수 항목에 넣었다.
