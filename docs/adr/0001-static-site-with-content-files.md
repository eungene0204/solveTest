# 정적 사이트 + 저장소 안의 콘텐츠 파일

문항은 `content/problems/*.yaml`로 저장하고 정적 사이트로 빌드한다. CMS·데이터베이스·서버를 두지 않는다. 운영자가 한 명 수준이고 수익이 광고뿐이라 운영비가 거의 없어야 하며, 해설의 모든 수정이 git 이력으로 남고(검수·수정 기록), 수식을 빌드 시점에 렌더링해 검색엔진이 읽을 수 있기 때문이다.

## Consequences

- 운영 도구는 “파일 편집 + `npm run dev` 미리보기 + 빌드”다. 비개발자 편집자가 늘면 CMS를 다시 검토한다.
- 런타임 기능(오류 신고 수신, 분석)은 외부 서비스에 맡긴다.
- 처음에는 Astro 5로 만들었고, Next.js 정적 export로 옮겼다(ADR 0005).
