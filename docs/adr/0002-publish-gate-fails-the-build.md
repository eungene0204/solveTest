# 공개 조건은 빌드 실패로 강제한다

검수 기록(정답 대조, 풀이 검수, 모바일 미리보기, 고난도는 독립 재풀이)이나 형식 요건이 빠진 문항을 `status: published`로 두면 `npm run build`가 실패한다(`publishBlockers`). 오답 해설이 공개되는 것이 이 서비스의 가장 큰 위험이고, 사람의 체크리스트는 빠뜨리기 쉽기 때문이다. 같은 목록을 미리보기 배너로 보여줘 남은 일을 알 수 있게 한다.

## Consequences

- 배포 빌드에서 초안은 페이지 자체가 생기지 않는다. 비어 있는 페이지를 검색에 노출하지 않는다는 원칙과도 맞는다.
- 검사를 추가할 때는 `publishBlockers` 한 곳에만 넣는다.
